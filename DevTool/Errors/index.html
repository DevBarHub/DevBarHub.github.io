Error Code: (P)
Error message, Check our website for solutions and to find out why this happens (P)

What does this mean?

This is a Permission Error. The command requires permissions that you or the bot do not currently have.

Possible Solutions

  • Make sure you have the required permissions.
  • Check if DevTool has Administrator permissions.
  • Verify the bot's role is above the target user.
  • Check channel permission overrides.
Error Code: (C/W)
Error message, Check our website for solutions and to find out why this happens (C/W)

What does this mean?

This is a Cooldown Error. The command has been used too recently and must wait before being used again.

Possible Solutions

  • Wait for the cooldown timer to expire.
  • Do not spam commands repeatedly.
  • Some commands have longer cooldowns than others.
  • Try the command again after a few seconds.
