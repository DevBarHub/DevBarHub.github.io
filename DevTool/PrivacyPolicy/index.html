Last Updated: May 31, 2026

1. Introduction

This Privacy Policy explains how DevTool collects, uses, and protects information when you use the bot in Discord. By using DevTool, you agree to the practices described in this policy.

2. Information We Collect

DevTool may collect the following types of data:

  • User IDs (Discord user identifiers)
  • Server IDs (Discord server identifiers)
  • Channel IDs (for command usage)
  • Command usage data (for functionality and debugging)

3. How We Use the Data

The collected data is used only to provide and improve DevTool features, including:

  • Executing commands properly
  • Preventing abuse or spam
  • Improving performance and stability
  • Debugging errors and issues

4. Data Storage

DevTool does not sell or share your data with third parties. Data is only stored when necessary for bot functionality and may be deleted at any time.

5. Data Security

We take reasonable measures to protect stored data, but we cannot guarantee absolute security. All data is handled in a way that minimizes risk.

6. Third-Party Services

DevTool operates through Discord and may rely on third-party services. We are not responsible for how Discord handles your data.

7. User Rights

You may request data removal by contacting the support server. Server owners can also request removal of server-related data.

8. Changes to This Policy

This Privacy Policy may be updated at any time. Continued use of DevTool means you accept any changes.

9. Contact

For questions or data removal requests, contact the DevTool support server.
